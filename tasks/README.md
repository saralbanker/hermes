# tasks/
One file per multi-session task: `tasks/<id>.md`. Keep it current; resume from it, not re-exploration.
Sections:
- Goal: one sentence, what "done" looks like
- Decisions: choices made + why (so they are not re-litigated)
- Next step: the single next concrete action
- Open questions: what needs the user or more evidence
Delete the file when the task is complete.
